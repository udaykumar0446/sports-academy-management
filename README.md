# Sports Academy Management Website

Full-stack EWP project built with React + Vite, Java Spring Boot, Spring Data JPA and MySQL.

## Features
- Dark UI with neon-green accents, responsive layout
- Dashboard statistics and recent athlete list
- Athlete registration, listing, search, edit and delete
- REST API with MySQL persistence
- Sports program preview and placeholder pages for Coaches and Attendance

## Requirements
- JDK 17+
- Node.js 20+
- MySQL Server 8+
- VS Code with Extension Pack for Java (recommended)

## 1. Set up MySQL
Start MySQL Server. In MySQL Workbench or the MySQL command line, run:
```sql
CREATE DATABASE sports_academy;
```
Open `backend/src/main/resources/application.properties` and replace `YOUR_MYSQL_PASSWORD` with your local MySQL password. Do not publish your real password to GitHub.

## 2. Run backend
Open a VS Code terminal:
```powershell
cd backend
mvn spring-boot:run
```
The API runs at `http://localhost:8080`. Test `http://localhost:8080/api/athletes` in a browser; it should return `[]` initially.

If `mvn` is not recognized, install Maven or use the Maven wrapper generated by your IDE. Ensure `java -version` reports JDK 17 or later.

## 3. Run frontend
Open a second terminal:
```powershell
cd frontend
npm install
npm run dev
```
Open the local URL printed by Vite, usually `http://localhost:5173`.

## API endpoints
- `GET /api/athletes`
- `POST /api/athletes`
- `PUT /api/athletes/{id}`
- `DELETE /api/athletes/{id}`
- `GET /api/dashboard`

## Notes
This is a classroom-ready starter, not a production deployment. Authentication/roles, coach CRUD, attendance CRUD, validation hardening and deployment should be added before real-world use. The Coaches and Attendance pages are clearly marked as upcoming modules.
